# Wren

A fictional AI thinking partner. Wren reads what you share, asks before it assumes and writes alongside you.

## Run

```sh
pnpm install
pnpm dev --port 3201
```

Next.js · React · Tailwind CSS · fully customized shadcn/ui (Base UI). Prompts, the composer, style menu, draft versions, tone and length controls, project files, tabs, seat stepper, pricing toggle, FAQ and mobile navigation work with the keyboard. Motion respects reduced-motion preferences. Fonts are local.

## Interactive demo

The hero holds a working chat. Wren drafts a board memo on its own: you see the steps it takes, then the answer streams in while the draft writes itself on the right. Ask for the risks and add them to the draft, make it shorter to get a second version, switch between versions, change the answer style or type your own message. Further down, change the tone and length of the same message, add files to a project and watch the answer and the context meter change, and browse four use cases that show what Wren read and checked.

The company, files, answers and prices are invented. Answers are pre-written, nothing is sent and nothing leaves the page.
