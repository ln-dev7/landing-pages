# Kudo

A fictional suite of six apps for creators: tips, memberships, a shop, paid calls, courses and letters, all on one creator page.

## Run

```sh
pnpm install
pnpm dev --port 3202
```

Next.js · React · Tailwind CSS · fully customized shadcn/ui (Base UI). The apps menu, tabs, creator page modules, steppers, previews, FAQ and the mobile menu card work with the keyboard. Motion respects reduced-motion preferences: the dithered patterns stop moving and the dot transitions become instant. Fonts are local.

## Interactive demo

Pick an app in the tabs and the headline, the dithered background and the creator page change with it. Send a tip and watch the goal fill, choose a membership tier, add pieces to the bag, book a call, mark a lesson as done or subscribe to the letters. The hero creator page takes tips too, the app previews react to clicks and the support desk updates on its own.

The dot patterns are drawn on canvas with ordered dithering, including the giant wordmark in the footer.

The creators, numbers and prices are invented. Nothing is saved and nothing leaves the page.
