# Folio

A fictional workspace for docs, wikis and project tables, with an assistant that has read every page.

## Run

```sh
pnpm install
pnpm dev --port 3199
```

Next.js · React · Tailwind CSS · fully customized shadcn/ui (Base UI). The page tree, to-dos, block menu, database views, status chips, Ask Folio prompts, block reordering, template filters, pricing switches, FAQ and mobile navigation work with the keyboard. Motion respects reduced-motion preferences. Fonts are local.

## Interactive demo

The hero holds a working workspace. Open pages from the tree, fold sections, tick to-dos, change the page icon, add blocks from the + menu and switch the launch tasks between table, board and calendar. Ask Folio summarizes the page, lists what is still open from the live state of the page and drafts an email; hover a source number to see the block it read. Further down, drag blocks to reorder them and turn one into another type, play with the same database in a larger view, filter templates and switch Folio AI on or off in the prices.

The company, pages, people and prices are invented. Nothing is saved and nothing leaves the page.
