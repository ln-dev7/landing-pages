# Plumb

A fictional product-analytics tool you question in plain words. Ask why a metric moved and Plumb answers with the chart, the segment behind it and the cause.

## Run

```sh
pnpm install
pnpm dev --port 3192
```

Next.js · React · Tailwind CSS · fully customized shadcn/ui (Base UI). Tabs, FAQ accordion, pricing toggle and mobile navigation are keyboard accessible. Motion respects reduced-motion preferences: the intro, beams and streamed answers appear instantly. Fonts are local.

## Interactive demo

The hero is a working mock of the product. On load, the page frame draws in, six data sources send pulses down their beams into the workspace, and a first question is asked and answered live. Switch the date range, pick a suggested question or type your own. Answers are pre-written; each one highlights what changed on the chart and shows the segment, the impact and the reason. Anything else you type gets an honest “demo only” reply. The sidebar switches between working views: Ask Plumb history, Watchers you can pause and expand, Funnels by platform, a Retention heatmap by plan, a searchable People list, Experiments with confidence and guardrails, and two pinned boards.

All data, customers, workspaces and prices are invented. No account is created, nothing is stored and nothing you type leaves the page.
