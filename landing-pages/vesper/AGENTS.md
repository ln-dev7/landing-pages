# Vesper

Standalone Next.js concept for a fictional end-of-day team digest. Keep the dusk art direction: a night-to-ember sky, hills and pointillist blossom shrubs drawn in SVG with a seeded random so server and client match, light Crimson Pro display over Albert Sans, a paper-coloured page below the hero and a dawn scene to close. The sky must keep reacting to the number of sign-offs. Animate numbers with NumberFlow and micro-interactions with Motion; keep them subtle and respect reduced motion. Everything is invented; never imply a real account or integration. Run typecheck and a production build, and verify desktop/mobile layouts plus the autoplayed sign-offs, manual sign-offs, replay, the sent state, pricing, FAQ, mobile menu and reduced motion in the browser.
