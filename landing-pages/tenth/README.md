# Tenth

A fictional card for people who work for themselves. Every payment is split the moment it lands, so tax is set aside before it can be spent.

## Run

```sh
pnpm install
pnpm dev --port 3207
```

Next.js · React · Tailwind CSS · fully customized shadcn/ui (Base UI). The share selector, calculator sliders, FAQ and mobile navigation work with the keyboard. Motion respects reduced-motion preferences. Fonts are local.

## Interactive demo

The headline opens around the card. The card tilts towards the pointer, payments arrive one after the other, and the two balances beside it count up: what is yours on the left, what is set aside on the right. Change the share from 15 to 25 or 30 percent and both balances follow. Further down, a calculator shows what a year of setting aside looks like for any monthly income and share.

The card, the people, the figures and the prices are invented. Nothing here is financial or tax advice.
