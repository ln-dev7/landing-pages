# Keel

A fictional issue tracker for product teams. Plan cycles, triage bugs and watch the roadmap move, all from the keyboard.

## Run

```sh
pnpm install
pnpm dev --port 3198
```

Next.js · React · Tailwind CSS · fully customized shadcn/ui (Base UI). The workspace views, status circles, board cards, command menu, keyboard keys, tabs, member stepper, pricing toggle, FAQ and mobile navigation work with the keyboard. Motion respects reduced-motion preferences. Fonts are local.

## Interactive demo

The hero holds a working workspace. Click a status circle and the issue moves to its next group, create issues with the button, switch between list, board, active cycle, roadmap and inbox, drag cards between board columns, open a project to see its milestones, or press ⌘K for the command menu. Keel Assist suggests duplicates, reviewers and estimates for the selected issue. Further down, press C, S, P, A, L or X on your own keyboard to edit an issue without the mouse.

The team, issues, customers and prices are invented. Nothing is saved and nothing leaves the page.
