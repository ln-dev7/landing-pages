# Hum

A fictional team chat with channels, threads, huddles and a catch-up that reads the backlog for you.

## Run

```sh
pnpm install
pnpm dev --port 3200
```

Next.js · React · Tailwind CSS · fully customized shadcn/ui (Base UI). Channels, reactions, threads, the composer, huddle controls, catch-up links, sliders, day toggles, switches, steppers, pricing toggle, FAQ and mobile navigation work with the keyboard. Motion respects reduced-motion preferences. Fonts are local.

## Interactive demo

The hero holds a working workspace. Switch channels, react to messages, open a thread and reply, start a huddle with a live timer and mute button, and send a message: a teammate starts typing and answers. The catch-up on the right writes itself and each line jumps to the message it summarizes. Further down, drag the unread slider to see the catch-up grow, set quiet hours and watch notifications wait or come through, switch workflows on and see what they post, and size the bill on active members only.

The workspace, people, messages and prices are invented. Nothing is sent and nothing leaves the page.
