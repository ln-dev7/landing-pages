# Vesper

A fictional end-of-day digest for teams. Everyone signs off with three lines, and Vesper turns them into one page the whole team reads at six.

## Run

```sh
pnpm install
pnpm dev --port 3204
```

Next.js · React · Tailwind CSS · fully customized shadcn/ui (Base UI). The sign-off buttons, replay, pricing, FAQ and mobile navigation work with the keyboard. Motion respects reduced-motion preferences. Fonts are local.

## Interactive demo

The hero is a dusk landscape drawn in code: hills, blossom shrubs and fireflies. In front of it sits tonight's digest. Teammates sign off one after the other, their lines land under Shipped, Stuck and Tomorrow, and the sky gets darker with each sign-off until the stars come out and the page is sent. Sign people off yourself in any order, or replay the evening.

The team, the companies, the quote and the prices are invented. Nothing is sent and nothing leaves the page.
