# Knot

A fictional AI automation tool. Describe a chore in one sentence and Knot wires the apps, tests the steps and keeps it running. Neo-brutalist: ink borders, hard shadows and loud flat colour.

## Run

```sh
pnpm install
pnpm dev --port 3195
```

Next.js · React · Tailwind CSS · fully customized shadcn/ui (Base UI). The canvas, recipe filters and cards, guardrail switches, stepper, pricing toggle, FAQ accordion and mobile navigation are keyboard accessible. Motion respects reduced-motion preferences: sentences and steps appear at once and runs finish instantly. Fonts are local.

## Interactive demo

The hero is a working canvas. Pick a sentence and Knot types it, then builds the steps one by one. Drag the steps around (or focus one and use the arrow keys), click a step to inspect it or switch it off, then press Run test: each step lights up, packets travel along the connections and the run log fills in. The demo-booked recipe takes a yes/no branch. Below, point at parts of a sentence to see the step each one becomes, flip recipe cards (three open straight in the canvas), drag the hero stickers, and change the guardrails to see what lands in your inbox.

Apps, customers, runs and prices are invented. Nothing is connected and no message is sent.
